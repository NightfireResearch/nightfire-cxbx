# The driving engine's functions (Driving.xbe) by subsystem, for tools/function_coverage.py --driving.
#
# Four tiers, from the bottom up:
#   sys       system APIs: Microsoft's XDK libraries (D3D, DSOUND, XPP), XAPI and the kernel thunks, the C/C++ runtime
#   platform  EA's platform layer: EAGL (graphics), the sound library, files, memory, threads, timers, maths, movies
#   engine    the game engine: animation, rendering, cameras, physics, world and collision, audio framework, input,
#             data and tuning, the game loop, scheduler and event framework, utilities
#   game      gameplay: AI, mission script events, missions and rules, vehicles, weapons and objects, the HUD and front
#             end (the G* classes), gameplay audio and effects
#
# The binary is laid out by source file, and the game's files are named after their classes, which carry a prefix:
# Act (animation), AI, A (audio), D (data), E (events, and EAGL), G (graphics: HUD and front end), I (input),
# P (vehicle physics), R (rendering), S (simulation and missions), U (utilities), W (world). So classification is by
# name, with address ranges for the libraries and for each area's default.
#
# RANGES: "range <address> <subsystem> <description>". A range runs to the next one. A sys.* range is fixed: every
# function in it is that subsystem. In any other range each named function is classified by the first class rule
# its class matches; one that matches none, and each unnamed function (FUN_...), takes the subsystem of the nearest
# named function before it in the same range, or the range's own subsystem if there is none. Only "anchors" count
# as that neighbour: a class whose functions sit close together, not one whose inline copies are scattered through
# the binary (EAGL, std, VU0, URefCounter...: a class whose functions span more than 0x8000 bytes, unless the
# function's neighbour is of the same class).
#
# FLOAT: "float <regex>": classes that never count as the neighbour, however close together their functions sit -
# templates and library helpers instantiated wherever they are used (URefCounter<AStream> inside the audio code).
#
# CLASSES: "class <regex> <subsystem>", matched (first match wins) against a function's class: the first component
# of a "A::B::f" name, the part before "__" of an exception-handling funclet ("PBondCar__ControlTyreTracks_Unwind_0"),
# or else the name up to its first underscore ("VU0_v4sub" -> "VU0", "MEM_size" -> "MEM").
#
# FUNC: "func <address> <subsystem>": one function, whatever the rules say - a copy compiled into another unit.
#
# `python tools/function_coverage.py --driving --unclassified` lists named functions no rule matches.
