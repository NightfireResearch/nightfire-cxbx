# The action engine's code by subsystem, for tools/function_coverage.py.
#
# Each line starts a range that runs to the next line: start address, subsystem, module. The XBE lays Eurocom's
# objects out roughly alphabetically by source file, so a module is a run of one file's functions (the names make
# the boundaries plain: Anim..., BOT..., Break..., Bullet...). Subsystems are grouped by the part before the dot.
# Anything below "platform" or "lib" is under the surface: Eurocom's Xbox layer (psi/xbox/d3d/dsnd - what the seams
# replace) and the XDK libraries linked in after it.
